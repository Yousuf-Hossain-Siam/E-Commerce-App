# 🛒 Flutter E-Commerce App

A modern, feature-rich e-commerce mobile application built with Flutter, showcasing clean architecture and contemporary UI patterns.

## ✨ Features

- **Modern UI/UX**: Smooth shimmer loading effects and responsive design
- **Product Catalog**: Browse products with staggered grid layout and detailed views
- **Shopping Cart**: Add, remove, and manage items with persistent storage
- **State Management**: Powered by Riverpod 3.0+ for reactive state handling
- **Navigation**: Seamless routing with GoRouter
- **Offline Support**: Local data persistence with Hive and SharedPreferences
- **Cross-Platform**: Supports iOS, Android, Web, macOS, Linux, and Windows

## 🏗️ Architecture

- **Clean Architecture**: Separation of concerns with data, domain, and presentation layers
- **Repository Pattern**: Abstracted data sources for better testability
- **Freezed Models**: Type-safe data classes with JSON serialization
- **Code Generation**: Automated boilerplate with build_runner

## 🛠️ Tech Stack

- **Framework**: Flutter 3.9+
- **State Management**: Riverpod 3.0
- **Navigation**: GoRouter
- **UI Components**: Staggered GridView, Rating Bar, SVG Support
- **Data Persistence**: Hive, SharedPreferences
- **Networking**: HTTP client
- **Code Generation**: Freezed, JSON Serializable

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd e_commerce
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Generate code**
   ```bash
   flutter packages pub run build_runner build
   ```

4. **Run the app**
   ```bash
   flutter run
   ```
